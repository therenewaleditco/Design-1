# How to use this folder

Upload this whole folder to a Claude Project (or Cowork's file/knowledge area). Once it's attached, tell Claude something like:

> "Use STYLE_GUIDE.md in Daily_Rituals_Style_Kit as the reference for tone, color, and fonts."

Claude will pull from `STYLE_GUIDE.md` for:
- Color palette (deep forest green + neutrals)
- Font pairing (script / editorial serif / mono / sans)
- Layout habits (sharp corners, image-heavy, mono eyebrow tags)
- Photography direction (grainy, warm, candid, collage-style)

Add real assets over time to make this more useful: the actual logo file, a few real photos you like, and the site's actual font files or Google Fonts links once you confirm them. Right now the fonts and hex codes are close visual matches, not values pulled from the site's code — swap in exact ones if you get them.
